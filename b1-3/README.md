# 미션 : 노코드 자동화 기초: 워크플로우 설계
## 1.[프로젝트 1] 자동화 도구 비교 구현

 #### 사용한 도구 이름
 Make Zapier

 #### 구현 과정 요약
  구글드라이브 업로드시 png,mp4 파일일경우 해당 폴더로 이동

 #### 비교항목
  |   | Make | Zapier |
  |:---   | :---:  | :---:  |
  | 접근성 | 약간의 초기진입장벽 | 우세 |
  | 무료버전기능 | 우세 | 무료플랜에서 분기점힘듬 |
  | 복잡도 | 우세 | 분기점때문에 |
  | 앱 생태계 | 약세 | 지원범위가 좀더 넓음 |
  | 시각적 디버깅 | 에러를 실기간으로 확인가능 | 부족 |

 #### 각 도구의 장단점 정리
 Make의 경우 UI/UX를 통해 워크플로우 흐름을 좀 더 보기좋게 커스텀가능
 
 Zapier의 경우 최초 습득시 좀더 익히기 쉬움/ 무료버전에서 분기점 나누기 까다로움
 #### 어떤 상황에서 적합한지 의견 작성
 처음 배우고 매우간단한 작업의경우 Zapier가 약간우세
 보다 복잡하거나 분기조건을 잘 쓰고싶다면 무료버전에선 Make가 우세
 
## 2.[프로젝트 2] 자유 주제 자동화 설계 및 구현

 #### 스팀 할인목록 정리
 #### 사용도구 Make
  좀 더 많이 사용하다보니 좀 더 편함
  워크플로우를 한눈에 알아보기 좋음
  무료버전에서 범용성이 더 좋음

 #### 워크플로우 흐름
 스팀 할인목록 페이지 스캔후 상위 10개항목
 게임이름,원가,할인율,할인가를 구글시트에 시간과함께 기록
